# bcschiffler.com

Personal website of Björn C. Schiffler, served with GitHub Pages.

Plain HTML and CSS with no build step and no third-party requests:

- `index.html`: the page
- `assets/css/style.css`: all styles, with light and dark themes following the system setting
- `assets/js/site.js`: a small lightbox for project figures (the page works without it)
- `assets/fonts/`: self-hosted Instrument Serif and Instrument Sans (SIL Open Font License, see `OFL.txt`)
- `images/work/`, `images/polymathic/`: optimized WebP images used on the page
- `imaging-pipelines/`, `journals_200.html`: standalone project pages linked from the site

To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
